Enterprise Enterprise Restaurant Performance & Benchmarking 

## 📊 Project Overview

The **Restaurant Sales, Orders & Profit Analysis Dashboard** is an interactive **Power BI data analytics project** designed to analyze restaurant business performance across different cities, restaurants, categories, order types, and franchise locations.

The dashboard transforms restaurant data into meaningful visual insights that help understand **sales performance, order trends, profitability, customer ratings, and business opportunities**.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze restaurant sales and order performance.
- Identify the highest-performing cities.
- Compare restaurant-wise profitability.
- Analyze profit contribution by food category.
- Understand customer ratings across cities.
- Compare Dine-in, Delivery, and Takeaway orders.
- Analyze franchise vs non-franchise performance.
- Track sales and profit trends.
- Identify areas for business improvement.
- Create an interactive dashboard for decision-making.

# 🔍 Business Recommendations

Based on the dashboard analysis:

1. **Focus on high-performing cities**
   - Use Austin as a benchmark for improving lower-performing cities.

2. **Promote high-performing restaurants**
   - Taco Fiesta can be used as a benchmark for order-generation strategies.

3. **Increase dessert sales**
   - Introduce dessert combos, discounts, and meal add-ons.

4. **Optimize restaurant categories**
   - Focus on high-profit Main dishes while improving lower-performing categories.

5. **Analyze order types**
   - Compare Dine-in, Delivery, and Takeaway performance to optimize operations.

6. **Improve lower-performing cities**
   - Identify reasons for lower sales and introduce location-specific marketing strategies.

7. **Monitor customer satisfaction**
   - Combine customer ratings with order volume to identify high-performing locations.
